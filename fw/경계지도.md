# fw 경계 지도 — 지금까지 찾은 유효 경계를 한 화면에

`fw/`(LLM 없는 결정 executive)가 sar 심판으로 검증되며 드러난 경계를 한자리에 모은다. 목적은
"fw 가 좋다"가 아니라 **어디까지 유효하고 어디서 무너지는지, 그 원인을 축별로 분리**하는 것이다.
근거 PR: #440(V&V) · #443(clutter) · #444(persistence) · #446(motion/NIS) · #447(fault injection).

## 1. 결합 스윕 — 한 화면 (확인창 N × 지속성 × 운동)

held-out 지리산 실제 DEM, clutter=0.20, n_ep=12. 각 칸 = **탐지율% / 오경보(평균/에피소드)**.
(`python3 sar/ivv/fw_vv.py --mode grid`)

| motion | persist | N=1 | N=2 | N=3 |
|---|---|---|---|---|
| static | 1 transient  | 12% / 2.2 | **21% / 0.3** | 0% / 0.2 |
| static | 4 persistent | 21% / 2.8 | 4% / **2.9** | 8% / **2.2** |
| const  | 1 transient  | 8% / 2.5 | **25% / 0.8** | 0% / 0.2 |
| const  | 4 persistent | 8% / 3.1 | 0% / **3.3** | 0% / **2.6** |

세 경계가 이 한 표에 다 있다:
- **열(확인창 N)**: N↑ 이면 오경보↓ 지만 탐지도↓. N=3 은 transient 서 오경보 최저(0.2)이나 탐지 0%
  (케이던스 과엄격). **N=2 가 transient 균형점**(21~25% 탐지, 오경보 0.3~0.8).
- **행 위/아래(지속성)**: transient(persist 1)면 N=2 오경보 0.3~0.8. **persistent(persist 4)면
  N 무엇이든 오경보 2.2~3.3** — 시간적 방어가 사라진다.
- **행 static/const(운동)**: 움직이는 표적은 탐지가 더 눌리고, **const+persistent 가 최악 코너**
  (N≥2 서 탐지 0%) — 두 문제(움직임·지속 clutter)가 겹친다.

## 2. 세 개의 직교 방어축 — 각자 무엇을 거르나

| 방어축 | 기전 | 거르는 것 | **못 거르는 것** | 대가 |
|---|---|---|---|---|
| 시간(temporal confirmation, N) | 연속 N스텝 같은 위치 | transient clutter(매 스텝 새 위치) | **persist ≥ N 지속 clutter** | 탐지↓·지연↑(N↑) |
| 운동(motion/NIS 게이트) | 예측 궤적과의 innovation d² | 점프·불가능 운동(NIS≈24) | **정지 false target(NIS 낮음)** | false negative(급회전·혼입 시 실탐 버림) |
| FDIR(safety supervisor) | 건강·충돌·전력·구동계·공분산 | dropout·저전력·충돌·actuator·공분산폭발 | **stale/stuck·bias 센서** | — |

## 3. 셋이 공통으로 멈추는 곳 — 단 하나의 gap

```
                     정지(static) · 일관(consistent) · 지속(persistent)  인 가짜 신호
                                          │
              ┌───────────────────────────┼───────────────────────────┐
              ▼                            ▼                            ▼
        시간: 지속되므로 통과        운동: NIS 낮으므로 통과        FDIR: 고장 아니므로 통과
              └───────────────────────────┼───────────────────────────┘
                                          ▼
                          세 방어 모두 무력 — 실표적과 구분 불가
```

**정지·고착·물리적으로 그럴듯한 가짜**(햇빛 데운 바위, 고정 다중경로, 고착 센서)는 시간으로도
운동으로도 FDIR 로도 못 거른다 — 실표적과 시간·운동·건강이 **모두 동일**하기 때문이다. 이건
kinematics·persistence·health 로는 원리적으로 풀 수 없고, **다른 채널**이 필요하다:
센서별 서명(외양/스펙트럼/열)·교차센서 물리 상관·bit-동일 반복(staleness) 탐지. 이것이 fw 의
**다음 축**이며 현재 없다(정직).

## 4. 그래서 지금 fw 는 어디까지 유효한가

- **유효**: transient clutter + (정지~등속) 표적에서, N=2 로 오경보를 baseline 의 1/3~1/8 로
  줄이며 탐지 20~25% 유지. dropout·저전력·충돌·actuator·공분산폭발에 FDIR 로 안전 열화. 결정적
  재생(동일 입력→동일 행동)으로 IV&V 가능.
- **무효(경계 밖)**: 지속 false target(persist ≥ N), 정지·고착·bias 센서, 고속/가속으로 FOV 이탈
  하는 표적(nav 한계), 케이던스가 N 을 못 채우는 경우(N=3 탐지 0%).

## 정직 — 이 지도의 한계

- n_ep=12~16 이라 **칸의 절대수치는 노이즈**가 있다(예: static/persistent N=1 21% vs N=3 8% 는
  노이즈). 결론은 **축별 방향성**(N↑→오경보↓·탐지↓, persist≥N→시간방어 소멸, 정지가짜→세 축 모두
  통과)에서 오고, 이는 여러 실행에 일관됐다.
- **dwell 은 독립 축으로 못 넣었다** — 현재 nav 는 belief 추종만이라 dwell 이 운동·nav 에 결합돼
  있다. 독립 dwell 스윕은 nav 를 손대야 하는 다음 작업이다.
- clutter 신뢰도를 실탐지와 같은 분포로 줬으므로(신뢰도만으론 못 거름) 위 이점은 오직 시간·운동·
  FDIR 기전에서 온다.
- 이것은 **배선·행동 골격의 경계 지도**이지 실비행 인증이 아니다.
