# newsdig -- 6시간 뉴스 브리핑의 틀

`dig/`(긁어모으기) + `brief/`(관문)를 Claude 예약 작업용으로 옮긴 것이다.
**도는 모델은 가장 가벼운 것(Haiku)이다.** 가벼운 모델은 긴 지시문의 뒤쪽 규칙을 놓친다.
그래서 규칙을 지시문에서 빼서 **코드로 옮겼다** -- 순서는 `step.py` 가, 판정은 `gate.py` 가,
레이아웃은 `render.py` 가 쥔다. 모델은 칸만 채운다.

```
step.py ──> doors(문 ~55곳: GDELT 6개 언어 · Google News 9개 지역 · 피드 · 검색 16)
        ──> weather ──> candidates.jsonl ──> 원문 열기(코드가 최대 30개 고름)
        ──> items.json ──> gate.py(B001~B006, L001) ──> render.py ──> FINAL
```

| | 무엇을 보나 | 못 지나면 |
|---|---|---|
| B006 | 후보의 주소·제목이 **문 원문**에 실제로 있나 | 후보가 못 된다 -- 지어낸 주소 |
| B002 | `articles/<id>.txt` 가 있고, 첫 줄 URL 이 맞고, 발췌가 원문에 **글자 그대로** 있나 | 화면에 안 나간다 |
| B003 | 12시간 안(모자라면 36시간) | 〃 |
| B004 | 쓴 **숫자**와 **라틴 고유명**이 원문에 있나 | 〃 |
| B005 | '최초' '유일' 같은 단정 | 경고 |
| L001 | 길이 · 갈래당 3(최대 4) · 지역 3곳 · 미국 절반 이하 | 코드가 고른다 |

## 이 관문이 못 보는 것

- 한국어로 옮긴 **뜻**이 원문과 같은지. 숫자와 이름만 기계로 맞춘다. 나머지는 링크로 사람이 본다.
- WebFetch 가 원문을 **요약해서** 돌려준 경우. 발췌가 그 요약에서 나오면 통과한다.
- 그 기사가 **중요한지**. 기계의 관할이 아니다.

