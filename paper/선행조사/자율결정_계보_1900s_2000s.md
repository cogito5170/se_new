# 선행조사 — 자율 결정 구조의 계보 (1900년대 → 2000년대, 그리고 SE 의 어디에 있나)

요청(사용자): "1900년대(1900~1999) 자율제어·로봇·AI·우주비행 소프트웨어 기술을, LLM 없는 결정
아키텍처를 2000년대식으로 재구성하는 관점에서 계보로 정리하라. **낡아서 버리는 게 아니라 당시
핵심 아이디어를 2000년대 계산환경·검증·소프트웨어 구조로 승격**시킨다."

## 연도순 뿌리 (원 시스템 → 현재 대응)

- **1960 Kalman filter** — 예측·보정 상태추정. 현재: 센서/상태 추정기의 수치 기반. `[출처:조각]`
- **1970s Expert systems / STRIPS planning** — IF-THEN·행동 시퀀스. 현재: policy/guard·BT/HTN. `[출처:조각]`
- **1986 Subsumption (Brooks)** — 계층 반응 behavior, 상위가 하위 suppress(=arbitration 이 구조에 내장). `[출처:조각]`
- **1980s NASREM (NBS)** — mission→task→sensory processing→world modeling→decomposition→servo 계층. `[출처:조각]`
- **1990/1997 Blackboard for robots** — sensor/knowledge subsystem 통합, behavior coordination. `[출처:조각]`
- **1990s 3T (Gat 등)** — deliberator/sequencer/reactive 3층, 심의는 항상 안 돈다. `[출처:조각]`
- **1990s POMDP** — 관측 불확실 → belief distribution·active perception. `[출처:조각]`
- **1999 Remote Agent / Deep Space 1** — mission manager→planner/scheduler→executive/diagnostics→RT. **실 우주선 비행.** model-based programming·onboard deduction·goal-directed closed-loop. `[출처:조각]`

핵심 논거: **Remote Agent 가 1999년에 이미 실 우주선에서 자율 planning/execution 을 했다** → "LLM 없으면 자율 시스템 못 만든다"는 전제는 역사적으로 틀리다. `[출처:조각]`

## SE 가 이미 가진 것 vs 아직 아닌 것 (우선순위 10)

이미: ① FSM/HFSM(fw) · ② Subsumption/arbitration(fw arbiter+safety) · ③ Blackboard(fw) ·
④ behavior-based(fw/sar 정책) · ⑤ 3T(sar 심의 + fw 실행·반응) · ⑥ belief/evidence(fw+sar) ·
⑦ FDIR(fw safety) · ⑩ telemetry→IV&V(sar/ivv, sar 가 심판).

**폐루프로 닫음(fw, PR 이후)**: ⑧⑨ **Planner**(`fw/planner.c` — HTN 식 순차 SEARCH→APPROACH→
INSPECT→REPORT + 컨틴전시 재계획; 3T sequencer/Remote Agent executive) · **Kalman**(`fw/estimator.c`
— 축별 스칼라 정위치 KF, belief.sigma 를 √trP 로 승격) · **replay**(host_test: 동일 입력→동일
행동열 결정성 = IV&V 기반). 이로써 Planner→Executive→Estimator→FDIR→Replay→IV&V 가 하나의
폐루프. 이 계보 문서가 fw 의 **architecture specification** 이 된다.

아직(후보): **EKF/UKF·상태 [x,y,vx,vy]**(fw 는 축별 스칼라 정위치 KF) · **풍부한 HTN task
network·동적 재계획 탐색**(fw 는 최소 순차) · **model-based reasoning** 추론엔진 · **기록된 센서
로그 replay + fault injection**(현재는 결정성 확인까지; 로그 재생·주입은 다음) · 실 표적 **motion·
dwell** 축의 V&V(nav 손대야 함).

## 아직 못 지운 가능성

- **원 논문 전문을 안 읽었다** — Remote Agent 의 executive 의무, 3T 의 심의 계약, NASREM 의 층
  정의가 여기 요약과 다를 수 있다. 전부 `[출처:조각]`.
- **NASREM/Remote Agent 의 정확한 계보 연결**(누가 무엇을 이었나)을 1차 자료로 확인 못 했다.
- **Kalman → belief** 승격을 수치로 잇지 않았다(fw 는 KF 가 아니라 감쇠·soft vote). 진짜 KF 를
  얹으면 belief 의 sigma 가 원리적으로 나온다 — 아직 안 함.
- 임베디드 자율에서 **BT vs HTN vs executive** 선택을 정면 비교한 2000년대 서베이를 아직 못 봤다.
- 이 계보에 **없는 20세기 갈래**(퍼지 제어, 신경망 1세대, 유전알고리즘, 강화학습 초기)를 뺐다 —
  결정 executive 와 덜 직결이라 보류했지만, 빠진 것을 여기 명시해 둔다.
