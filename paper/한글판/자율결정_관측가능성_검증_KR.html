NASA 소프트웨어·모델시뮬 assurance 를 따라 모든 결과에 fidelity 등급을 붙이고 verification 과 운용 validation 을 엄격히 분리한다. 부정 결과는 감추지 않고 남긴다.

참고문헌

1. 서론

1.1 동기

자율 결정이 이제 대형 언어·기반 모델을 요구한다는 통념이 있다. 역사적으로 이는 거짓이다: NASA 의 Remote Agent 는 모델 기반 고장 보호를 갖춘 자율 계획-일정-실행 구조를 1999년 Deep Space One 에서 비행시켰다 [출처:조각]. 따라서 우리의 전제는 소프트웨어가 관측을 구조화하고 미리 정의된 결정 원자를 조합할 수 있다는 것이며, 흥미로운 공학적 질문은 어느 알고리즘인가가 아니라 주어진 센서 집합과 결정 규칙을 어디까지 믿을 수 있는가 — 주장이 아니라 검증으로 답하는 질문이다.

1.2 접근

우리는 고전 자율 계보로 결정 executive 를 짓고, 독립 물리 심판에 부치고, 심판에게 경계를 그리게 한다: 온보드 정보가 어떤 거짓 신호 부류를 거를 수 있고 어떤 것은 어떤 규칙 설정으로도 못 거르는가. 표제 정확도 수치가 아니라 이 경계가 결과다 — 그리고 경계가 새 채널을 요구하는 곳에서, 그 요구는 처음부터 가정된 것이 아니라 실험으로 산출된 것이다.

1.3 기여

다섯 기여는 모두 방법론적이다. C1: 고전 자율 계보를 마이크로컨트롤러에 맞는 분리 가능·힙 없는 층으로 구현한 OS 없는 C 결정 executive. C2: 물리 심판이 숨은 truth 를 쥐고 어떤 선수든 채점하며, 결정이 결정적으로 replay 되고, 고장 응답이 objective evidence 로 측정되는 독립-V&V 하네스. C3: 확인창·clutter 지속성·표적 운동의 결합 스윕으로, 세 독립 방어가 한 실패영역을 공유함을 보이는 관측가능성 경계 방법. C4: 그 경계에서 판별형 liveness 채널의 필요를 도출하고 이식된 C executive 에서 재현하는 교차 물리 상관 연구. C5: 명시적 fidelity 사다리와 verification/validation 경계, 양방향 traceability — 그래서 어떤 시뮬 수치도 운용 주장으로 읽히지 않게 한다.

1.4 구성

2절은 V&V 용어와 fidelity 사다리를 고정하고, 3절은 reference world 를 독립 심판으로 기술하며 모든 센서 모델의 지배 방정식을 준다. 4절은 각 정책의 수식과 배포 코드를 갖춘 executive 구조, 5절은 verification 방법, 6절은 관측가능성 경계, 7절은 교차 물리 상관과 도출된 liveness 요구, 8절은 traceability, 9절은 한계와 부정 결과다. 부록 A·B 는 배포 코드와 센서 모델 파라미터를 싣는다.

2. 검증·확인 틀

2.1 소프트웨어 V&V 와 독립 V&V

NASA 소프트웨어 공학 요구(NPR 7150.2)는 verification("옳게 만들었나?")과 validation("의도한 환경에 옳은 것을 만들었나?")을 분리하고, 둘 다 생명주기에 걸쳐 계획하도록 하며, 요구에서 설계·코드·시험을 거쳐 결과까지 양방향 traceability 를 강제한다 [출처:조각]. 소프트웨어 보증·안전 표준(NASA-STD-8739.8B)은 독립 V&V 를 기술·관리·재정 독립으로 보고, off-nominal 행동(고장·위해 응답)을 개발자 주장이 아니라 objective evidence 로 평가하도록 한다 [출처:조각]. 시스템 공학 핸드북은 V&V 를 공학 생명주기 안에 둔다 [출처:조각]. 우리는 이 용어를 그대로 채택하고, verification 근거와 validation 근거를 시종 다른 칸에 둔다.

2.2 검증 가능한 산물로서의 모델·시뮬

NASA-STD-7009 는 모델·시뮬 자체가 그 출력이 결정을 뒷받침하기 전에 verify·validate·credibility 평가를 받도록 요구한다 [출처:조각]. 따라서 시뮬 결과는 그 모델의 fidelity·credibility 에 의해 한계 지어진 verification 근거이지 운용 validation 이 아니다. 비행 실무가 이를 보인다: Mars 2020 의 지형상대항법(TRN)은 고fidelity 시뮬과 현장·HITL 시험을 병행했고 [출처:조각], 자율착륙 위험회피·정밀착륙 프로그램은 몬테카를로 시뮬·현장·HITL 을 병행했으며 [출처:조각][출처:조각], reference map 은 렌더 파이프라인으로 짓고 실 비행 영상에 대조해 검증했다 [출처:조각]. core Flight System 은 우리가 축소해 본뜬 component+executive 구조의 예다 [출처:조각]. 그래서 우리는 센서·decoy·liveness 모델을 model-V&V 미수행의 대표 물리로 다루고, 수치가 이 모델에 의존하는 곳마다 그렇게 밝힌다.

2.3 Fidelity 사다리

모든 결과를 fidelity 사다리에 놓는다. 아래 계단은 verification, 위 계단은 validation(표 1)이다. 이 연구는 L2(실측 지형 + 물리 센서모델)에 있고, 여기 어떤 것도 L3 이상으로 제시하지 않는다.

3. 독립 심판으로서의 reference world

3.1 한 장면의 세 역할

평가 환경은 그림이 아니다. 지형·역학·센서·구동계·소프트웨어를 하나의 루프로 닫아 온보드 소프트웨어를 숨은 truth 에 대해 반복 구동하는 NASA 모델시뮬 실무를 따라 [출처:조각], reference world sar/ 는 세 역할을 동시에 한다: ground-truth 생성기(실측 DEM + landcover 위에 놓인 숨은 표적·decoy·liveness), 물리 센서 시뮬레이터(3.2절), 시나리오 생성기(clutter·지속성·운동·dropout·decoy). 선수 — 결정 executive — 는 truth 를 결코 보지 않고 관측만 받으며, 그 행동은 별도 evaluator 가 숨은 상태에 대해 채점한다.

DEM(실측) + landcover + 장면 재질 │ ground truth: 숨은 표적 · decoy · liveness 물리 센서 모델(Planck · Koschmieder · LiDAR · GNSS · Audio) │ 합성 센서 관측 (선수는 이것만 본다) 센서선택 → 융합 → 추정(칼만) → FDIR → planner → BT → arbiter → safety filter │ 행동 독립 evaluator 가 행동을 숨은 truth 에 대해 채점 ↺
그림 1. 심판/선수 분리. 심판은 truth 와 다른 물리를 쥐고, 선수는 belief 만 쥐며, 로그를 기록하고 지표를 내는 검증 하네스는 구현과 분리돼 있다.

3.2 물리 센서 모델(Level-2 reference)

각 센서는 "truth + 가우시안" 이 아니라 생성 물리 + 신호처리 chain 수준으로, 문헌 대표값 [출처:조각] 으로 모델링한다. 이는 상용 시뮬레이터 재현이 아닌 Level-2 reference 다; 파라미터는 부록 B.

3.2.1 광학(RGB, ISETCam 계열)

장면 radiance 를 광전자로 적분한 뒤 shot·read·dark·PRNU 로 오염시키고 양자화한다. 안개는 Koschmieder 법칙으로 가시대역을 감쇠시킨다:

(1)Ne = ∫ E·QE·(λ/hc) dλ,   Ne ~ Poisson,   τvis = exp(−(3.912/V)·R)

3.2.2 열적외 LWIR(Planck + MODTRAN 계열)

장파 적외 복사휘도는 8–14 µm 대역에서 Planck 법칙을 적분해 얻고, at-sensor 복사휘도는 방사율과 대기 경로 항을 더한다. LWIR 소광이 가시 소광보다 작기 때문에 열대비가 연무·야간에 살아남는다 — 다만 짙은 물방울 안개는 여전히 감쇠시킨다(정직: 면역 아님):

(2)Lλ(T) = (2hc²/λ⁵) · 1/(exp(hc/λkBT) − 1)
(3)Lsensor = τ·(ε Lλ(T) + (1−ε) Lλ(Tamb)) + (1−τ) Lpath,   βLWIR = (3.912/V)·(0.15 + 0.65 e−V/150)

겉보기 열대비가 NETD 의 세 배를 넘으면 탐지 가능으로 판정한다, |ΔTapp| > 3·NETD, NETD = 0.05 K.

3.2.3 LiDAR(waveform)

수신 전력은 왕복 소광과 거리 역제곱으로 줄고, 거리는 TOF, 거리 표준편차는 펄스폭을 √SNR 로 나눈 값으로 커진다:

(4)Pr ∝ ρ·exp(−2βRrng)/Rrng²,   Rrng = c·t/2,   σR ≈ c·tpulse/(2√SNR)

3.2.4 관성(IMU, IEEE Allan 분산)

측정은 scale 오차·Gauss–Markov bias·백색잡음을 지니며, 위치 불확실도는 랜덤워크로 커지다 포화한다:

(5)am = (1+Se)a + b + n,   ḃ = −b/τ + w  (Gauss–Markov)

3.2.5 GNSS(pseudorange → 위치)

수평 위치오차는 DOP 와 UERE 에, 도심·협곡에서는 multipath 에 비례해 커지며, 가시위성 4 미만이면 outage 다:

(6)σpos ≈ HDOP·UERE + multipath,   nsat < 4 ⇒ 해 없음

3.2.6 음향(image-source 실내충격응답)

소리는 안개·수관·야간을 통과하는 — 광학과 물리적으로 구별되는 — 채널로, 구면확산과 대기흡수로 전파한다. 탐지는 소리-바람 비가 임계를 넘어야 하고, 마이크 배열이 방위를 준다:

(7)SPL(r) = SPL0 − 20 log10(r) − 0.005 r,   탐지 ⇔ SPL − SPLwind > 6 dB

이 다양성은 의도적이다: 환경 하나(안개·야간·수관·multipath)를 바꾸면 센서마다 raw→perception 이 다르게 무너지므로, 정책은 한 센서를 못 박지 않고 정보품질로 센서를 고른다(4.3절).

3.3 시나리오 생성기와 evaluator

시나리오는 clutter 밀도, clutter 지속성(순간 대 다스텝), 표적 운동(정지 대 등속), 센서 dropout, decoy 서명을 바꾼다. evaluator 는 각 실행을 숨은 truth 에 대해 탐지율(찾은 실표적)과 오경보/에피소드(실표적 없는 주장)로 채점하므로, 정책이 아무 데나 주장해 점수를 얻을 수 없다. 모든 실험은 held-out 지리산 실측 DEM 을 쓴다.

4. 결정 executive 구조

4.1 슈퍼루프와 blackboard

executive 는 하나의 정적 blackboard 와 힙 없는 슈퍼루프다. 한 패스: 센서·건강 → 센서선택 → 시간적 확인·교차모달 게이트·liveness 게이트를 갖춘 건강가중 증거융합 → 추정 → FDIR/안전 감독자 → planner → behavior tree → arbiter → 최종 safety filter. 동적 할당도 OS 도 없다. 모든 상태가 정적 크기의 blackboard 필드에 있어 메모리를 한계 짓고, 고정 타이밍·스택의 타깃에 대해 루프를 분석 가능하게 한다.

4.2 추정: 등속 칼만 필터와 NIS

축별 2상태 등속 칼만 필터(위치·속도)를 닫힌 꼴(행렬역 없음)로 유지한다. 단위 시간스텝에서 F = [[1,1],[0,1]], 가속잡음 과정 공분산 Q = q·[[¼,½],[½,1]]:

(8)x̂⁻ = F x̂,   P⁻ = F P Fᵀ + Q
(9)r = z − H x̂⁻,   S = H P⁻ Hᵀ + R,   K = P⁻ Hᵀ S⁻¹,   x̂ = x̂⁻ + K r,   P = (I − K H) P⁻

정규화 innovation 제곱은 갱신 전, 예측에 대해 재어 운동학 일관성의 결정 증거로 쓴다. 재초기화 한계를 넘으면 추적 상실 또는 새 표적으로 보고 그 자리에서 다시 씨앗을 놓는다:

(10)d² = rᵀ S⁻¹ r = rx²/(Px,00+R) + ry²/(Py,00+R),   d² > 50 ⇒ 재초기화

위치 불확실도 σ = √tr P 를 arbiter 와 공분산 가드(4.5절)에 내보낸다. 배포 코드는 목록 A.1.

4.3 센서 선택 정책

센서 선택을 주장에서 분리한다. 세 후보 selector 는 항법 코어를 공유하고 어느 센서의 탐지를 신뢰하는지만 다르다: baseline(RGB 만), NASA-S4 식 효용 규칙, 그리고 관측 문맥만으로 학습된 selective SSM(Mamba) 정책. 효용 규칙은 조건마다 탐지−비용−에너지 목적을 최대화하는 센서를 고른다:

(11)U(a | s) = D(a,s) − λ·C(a) − μ·E(a),   a* = argmaxa U(a | s)

비용 가중 λ = 0.30, 에너지 가중 μ = 0.10; 탐지 유틸리티 D(a,s) 는 reference 자신의 조건별 탐지확률(심판이 탐지를 생성하는 방식과 자기일관)이라, 학습 라벨은 관측 전 조건에서 나온 능동형 "이 조건서 어느 센서를 켤까"(인과 순서: 조건 → 센서 → 미래 탐지)이지 탐지-이벤트 라벨이 아니다. 센서별 비용표(RGB 0.10 … SAR 0.70)와 에너지표(RGB 0.10 … LiDAR 0.70)가 RGB 는 싸고 빠르며 SAR·LiDAR 는 느리고 전력이 큼을 담는다. 앞선 NASA-rule 변형은 Ui = ΔPi − α·costi (α = 0.35)에 히스테리시스 0.05 로 모드 떨림을 막는다. 학습 selector 는 관측 문맥만([가시도, IMU-ok, GNSS-불확실])을 쓴다; 직전 선택을 되먹인 이전 판은 자기강화 lock-in(RGB→RGB covariate shift)을 냈고 고쳤다 — 기록된 부정 결과다.

4.4 증거 융합: soft vote, 시간적 확인, 교차모달 게이트, liveness

융합은 개수가 아니라 건강가중이다. 가장 강한 present 센서가 앵커이고, 앵커의 공간 게이트 안 present 센서를 융합한다. 융합 신뢰는 clamp 된 가중합, 융합 위치는 신뢰가중 무게중심이며, 측정잡음은 신뢰가 높을수록 작다:

(12)anchor = argmaxi:present wi hi ci,   conf = clamp(Σi∈gate wi hi ci, 0, 1)
(13)(mx, my) = (Σ wi hi ci xi, Σ wi hi ci yi) / Σ wi hi ci,   R = 0.2 + 2.0(1 − conf)

투표 가중 w = {RGB 1.00, THERMAL 0.70, LIDAR 0.80, SAR 0.50, AUDIO 0.35}. soft vote 위에 세 게이트가 있고, 각각 6절의 관측가능성 분석이 동기다:

  • 운동학(NIS) 게이트. 확립된 추적에서 d² > γ 인 측정은 궤적과 모순(점프·불가능 운동)이라 확인 카운트에 안 넣는다 — 운동을 결정 증거로 삼는다.
  • 교차모달(CMPC) 게이트. 켜지면 후보를 가중합이 아니라 일치하는 서로 다른 물리채널 수(≥ Ncmpc)로 수락해 soft-vote 임계를 대체한다. 조건부 완화는 가림-강 채널(SAR/Audio)만으로 보이는 후보를 1채널에서 수락해 수관 진짜를 보존한다:
(14)detected = [ nmodal ≥ Nreq ],   Nreq = (Ncmpc≥2 ∧ 가림채널 없음 ∧ 전천후 있음)이면 1, 아니면 Ncmpc
  • Liveness 게이트. require-live 면 근접 생체징후(호흡·심박) 반환이 없는 후보를 기각한다 — 7절의 전-서명 decoy 를 제거한다.

끝으로 시간적 확인이 detected 이며 운동 일관인 재현을 연속 N 스텝 요구하고, 공분산 가드가 σ 상한 초과 시 확인을 취소한다(발산 하거나 오래 못 본 추적엔 행동 금지):

(15)confirmed = [ run(detected ∧ motion_ok) ≥ N ] ∧ [ σ ≤ σmax ]

배포 융합 코드는 목록 A.2; 정책 프로토타입과 실험이 동일하게 쓰는 교차모달 규칙은 목록 A.4 로, 둘 사이의 규칙 드리프트를 막는다.

4.5 고장 감지·격리·복구; 안전 감독자

안전 감독자가 센서 건강의 하향 교차(격리·복구 이벤트), 충돌, 저전력, 구동계 고장을 감지하고, 비상 > 귀환 > 열화 > 정상 우선순위의 모드 FSM 을 전이한다. 격리는 고장 센서를 빼되 나머지로 융합을 계속하고, 복구는 건강이 돌아오면 되살리며, 죽은 센서 둘 이상 또는 무효 IMU/GNSS 면 열화 모드로 간다. 코드는 목록 A.5.

4.6 계획과 behavior tree

planner 는 임무를 순서 있는 행동 집합 — 탐색·접근·관측·재정렬·귀환 — 으로 분해하고, 사전조건이 깨지거나 세계가 바뀌면 contingency 재계획을 한다(중간층의 순서화 역할). behavior tree 는 매 스텝 우선순위 행동을 제안한다.

4.7 Arbitration: 사전조건 후 효용, 효용 위의 안전

arbiter 는 사전조건을 만족하는 행동만 받아들이고, behavior-tree 제안이 부적격이면 적격 집합을 임무−벌점 효용으로 순위 매긴다:

(16)U(a) = mission(a) − 1.0·collision_risk − 0.3·energy(a) − 0.2·σ,   a* = argmaxa:precond(a) U(a)

확인 표적의 관측이 최고 임무가치(1.0·target_conf), 접근이 다음(0.7·target_conf), 탐색이 상수 바닥이다. 사전조건은 안전 여유를 담는다: 관측은 확인 표적·충돌 여유·전력 여유를 요구하고, 재정렬은 항법 상실 또는 감독자 열화 시의 복구 행동이다. 안전 제약이 효용을 지배한다. 코드는 목록 A.3.

4.8 Safety filter

safety filter 는 마지막·무조건 단계다: 구동계 고장은 안전 정지, 충돌 임박은 회피, 극저전력은 비상 또는 귀환, 자세 상실은 재정렬, 충돌 여유 부족한 접근·관측은 탐색으로 강등한다. planner·arbiter 의 어떤 행동도 override 할 수 있다(목록 A.6).

4.9 이식성과 심판 bridge

결정 코어는 ROS·Linux·GPU 의존이 없는 이식성 C 다. 같은 소스를 공유 라이브러리로 컴파일해 reference world 에서 foreign-function bridge 로 부르는데, 관측과 liveness 를 넣고 고른 행동과 filter 의 정규화 innovation 을 낸다. 그래서 심판이 임베디드 코드를 직접 채점하고, 7.4절의 C 이식본 재측정이 대리물이 아닌 배포 규칙의 측정이 된다.

5. Verification 방법론

5.1 결정적 replay

기록된 관측 스트림을 새 executive 로 재생하면 행동 순서가 정확히 재현된다. 이것이 불변식 검사의 근거이며, 뒤 절에서 규칙과 executive 를 정직히 가르는 바탕이다.

5.2 Fault injection

off-nominal 조건을 주입하고 응답을 objective evidence 로 기록한다. 못 막은 고장은 coverage 에 접지 않고 식별된 risk 로 남긴다(표 2).

5.3 하네스의 독립성(IV&V 근사)

검증 경로 — 로그를 기록하고 지표를 내는 하네스와 test_* — 는 구현과 분리해 짓고 돌린다. 결론은 개발자 주장이 아니라 그 독립 경로의 expected-vs-observed 근거에서 나온다 — 기술적 IV&V 독립성의 근사다.

7. 교차 물리 상관과 도출된 liveness 요구

7.1 방법: 정보집합을 넓히고 센서 개수는 고정

융합을 spatial voting("몇 개 봤나")에서 교차 물리 상관("사람이라면 함께 나와야 할 물리채널이 양립하나")으로 바꾸되 센서 개수는 5 로 고정한다. 탐지가 항법에 얽히면 규칙을 못 가리므로 둘을 분리한다: 시나리오마다 고정 경로 관측 스트림을 한 번 기록하고, 같은 스트림에 각 정보집합의 claim 규칙만 적용한다(진짜 replay — 입력 동일, 규칙만 다름). held-out 지리산, nep = 20 (sar/ivv/cmpc_vv.py). 네 정보집합: I0 spatial(≥1 모달리티); I1 strict CMPC(서로 다른 물리채널 ≥2); I1 cond CMPC + 식(14) 조건부 완화; I2 CMPC-cond + liveness 채널 요구.

7.3 답: 교차상관은 충분한가? 센서를 더해야 하는가?

  1. 단일모달 clutter(A)는 5센서로 닫힌다 — 센서 추가 불필요. CMPC(≥2)가 오경보를 1.8 → 0.1 로 죽인다; 대부분의 현실 clutter(multipath·고착 단일센서·고립 열점)가 여기다.
  2. 대가가 있다(B): 교차상관은 단일모달 진짜를 버린다. 수관+짙은안개로 SAR 만 보이는 진짜를 strict 는 100% → 15% 로 놓친다; 조건부 완화가 60% 로 회복하되 공짜가 아니다.
  3. 그 완화가 clutter 구멍을 다시 연다(A): 조건부 오경보 1.4, 가림-강 채널이 단일채널 clutter 를 통과시킨다. 단일모달 clutter 억제와 단일모달 진짜 보존을 kinematic·modal 규칙만으로 동시에 못 한다 — 트레이드다.
  4. 전-서명 decoy(C)는 5센서로 못 닫는다. RGB·Thermal·LiDAR·SAR 를 다 트립하는 decoy 는 CMPC(strict·cond)를 통과한다(오경보 0.9–1.6). 이는 CMPC 의 실패가 아니라 관측가능성 한계의 증명이다: 다섯 채널이 다 속으면 그 정보로는 원리적으로 decoy 와 사람을 못 가른다.
  5. liveness 채널(I2)만이 decoy 를 제거한다: 1.6 → 0.1, 그러면서 진짜 보존(B 55%)·단일모달 clutter 억제(A 0.1). 여기서 처음으로 센서 추가가 아이디어가 아니라 실험이 요구한 채널이 된다 — 생체징후 레이더가 반환을 위치시키는 게 아니라 미세운동으로 사람을 식별하는 것과 개념적으로 같다 [출처:조각].
공통 gap(정지 · 고착 · 일관 가짜) │ 교차 물리 상관(5센서)? ├─ 단일모달 clutter → 닫힘 (A: 1.8→0.1) [센서 추가 불필요] ├─ 단일모달 진짜의 대가 → 조건부 부분 회복 [트레이드] │ (B: 15→60%) └─ 전-서명 decoy → 안 닫힘 (CMPC 통과) [관측가능성 한계] │ liveness 채널 추가 ▼ decoy 걸림 (C: 1.6→0.1) [실험이 요구한 센서]

7.4 C executive 안에서 재측정(bridge ↔ 심판)

대리물이 아닌 배포 코드를 확인하려, liveness 를 bridge 로 C executive(fw/evidence.c)에 넣고 C 결정 코어를 같은 고정경로 스트림에 직접 구동한다. C 빌드는 조건부(배포형) CMPC 만 구현하므로 프로토타입(py)과 I0 / I1 cond / I2 에서 비교한다(held-out 지리산, nep = 20).

"수치가 같다"고 하지 않고 세 주장을 구분한다. (i) 규칙 등가성은 host test 로 정확히 확인된다 — 네 판정(단일모달 RGB 1채널 확인/2채널 기각, SAR 단독 조건부 확인, decoy CMPC 통과, liveness 요구 시 decoy 기각)이 프로토타입과 같다. (ii) 두 핵심 발견이 C 에서 방향·크기로 재현된다: 조건부 게이트가 부분관측 진짜를 대가 있게 보존(B: 90% → 30%, 양쪽), CMPC 는 decoy 를 못 거르고 liveness 가 제거(C → 0, 양쪽). (iii) 절대 오경보는 C 가 낮다(A: 3.0 대 1.6; C I2: 0.1 대 0.0). 이는 불일치가 아니라 executive 구조다: 무상태 프로토타입 scorer 는 매 관측의 모든 군집을 채점하는데, C executive 는 단일가설 stateful 추적이라 먼 clutter 를 덜 claim 한다. 규칙 등가·방향 재현·구조적 크기 차이는 서로 다른 세 진술이며 구분해 적는다.

정직 노트(단일 가설). 배포 executive 는 하나의 belief 가설을 추적하는데, 이는 오경보를 구조적으로 낮추지만 탐지도 낮추고 두 표적을 동시에 표현하지 못한다. C 의 낮은 오경보 크기는 규칙 불일치가 아니라 executive 성질이다 — 규칙은 위 host test 로 등가 확인됐다. 이는 자랑할 결과가 아니라 기록된 설계 선택이다.

9. 한계와 부정 결과

불리한 발견을 남긴다 — 그것을 감춘 경계 연구는 광고이기 때문이다.

  • 시뮬레이션만. 모든 수치는 L2 verification 이다; 센서·decoy·liveness 모델은 대표 물리이지 실 센서에 대해 검증된 것이 아니다(model-V&V 미수행).
  • gap 은 실재하며 온보드 집합으로 안 닫힌다. 정지·일관·지속 가짜(또는 고착 센서)는 시간·운동·고장관리로 안 풀리고, liveness 가 필요한데 심판에선 가정으로 모델링돼 있다 — 물리적 실현성은 여기서 검증하지 않는다.
  • 오경보 바닥은 한때 artifact 였다. clutter 없던 초기 설정이 오경보 0 을 냈는데, 그 0 은 정책이 아니라 장면의 성질이었다. clutter 를, 이어 지속 clutter 를 넣으니 artifact 가 사라지고 표 4 의 시간 한계가 드러났다. 그 교정도 기록의 일부다.
  • 조건부 완화는 진짜 트레이드이지 해결이 아니다. 단일모달 진짜(B)를 회복하는 대가로 단일모달 clutter 구멍(A)을 다시 연다; 양방향을 다 적는다.
  • selector 의 이전 피드백 특징이 lock-in 을 냈다. 직전 선택을 되먹이면 자기강화 covariate shift(RGB→RGB)가 났고, 그 특징을 빼고 라벨을 능동·조건 기반으로 바꿨다.
  • 표본이 작다. nep = 12–20 이라 칸의 절대값에 노이즈가 있다; 결론은 여러 실행에 일관된 축별 방향성에서 오지 어느 한 칸에서 오지 않는다.
  • dwell 은 독립 축이 아니다. 항법이 belief 를 추종하므로 dwell 이 운동에 얽혀 있다; 독립 dwell 스윕은 항법을 손대야 하며 후속으로 미룬다.
  • 단일 가설. 탐지가 상한 지어지고 다중표적 장면이 덜 다뤄진다 — C 의 낮은 오경보 크기도 설명하는 측정된 설계 선택이다.

10. 맺음말

LLM 없는 자율 결정 executive 를 V&V 대상으로 짜는 것은 구현 이상을 낳는다: 관측가능성 경계를 낳는다. 시간적 지속성·운동학 일관성·고장관리는 기존 5센서로 각각 다른 거짓 신호 부류를 닫지만, 정지·일관·지속 거짓 표적은 셋을 다 이긴다. 교차 물리 상관은 새 하드웨어 없이 단일채널 clutter 를 닫되 단일채널 진짜에 측정된 대가를 치르고, 그러고도 전-서명 decoy 를 허용한다 — 오직 판별형 liveness 채널만이 그것을 제거하며, 이는 직관이 아니라 실험으로 확립됐고 배포 C 코드 안에서 재현됐다. 모든 결과는 명시된 fidelity 수준의 시뮬 verification 으로 라벨링되며, 운용 validation 은 분리·열거·명시적 미수행으로 남긴다. 기여는 규율 있는 경로 — verification, 경계, 도출된 요구, 정직한 부정 결과, 그리고 validation 이 시작돼야 할 명확히 표시된 선 — 이다.
