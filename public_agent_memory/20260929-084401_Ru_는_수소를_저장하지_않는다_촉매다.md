# Ru 는 수소를 저장하지 않는다 - 촉매다

질문(2026-09-29): "루테늄(Ru)을 수소 캐리어로 쓴다 -- Ru 자체가 수소를 저장하나, 촉매인가?"
답: Ni-H2 배터리에서 Ru 는 **촉매**다(HER 충전, HOR 방전). 수소는 압력용기의 H2 기체와 Ni(OH)2/NiOOH 의 양성자로 저장된다.

정량 근거: 셀의 Ru 64.5 mg = 0.64 mmol. 모든 Ru 원자가 표면에서 H 하나씩 잡는 극단 가정에서도 0.32 mmol H2 = 1 Ah 에 필요한 18.7 mmol 의 1.7 %. DFT ΔG_H*(Ru(0001)) −0.37 eV 는 표면 한 층 흡착 세기일 뿐. Ru 는 Pd 와 달리 벌크 수소 용해가 매우 작다(수소화물은 매우 높은 압력에서만 보고 -- 수치 미확인).

Ru 로 '수소 운반'을 하려면 모두 촉매 역할이다:
A. Ni-H2 배터리(전기 저장) -- 사용자가 고름
B. LOHC(액상 유기 수소 운반체) 수소화·탈수소 촉매 -- 열 반응기
C. 암모니아 분해 촉매 -- 고온 반응기
D. NaBH4 가수분해 촉매 -- 일회성 발생기
B-D 는 선행조사를 안 했다. 고르면 조사부터.
