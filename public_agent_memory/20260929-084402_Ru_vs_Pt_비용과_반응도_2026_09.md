# Ru vs Pt 비용과 반응도 2026-09

Ru(루테늄)와 Pt(백금)를 Ni-H2 수소 전극(알칼리 HOR/HER) 촉매로 비교. 모델 + 검색 요약([조각]) 기반.

- **가격(2026-09, [조각])**: Ru 약 $1,675-1,750/oz, Pt 약 $1,751-1,811/oz -- 질량당 거의 같다. Ru 는 1년 새 약 +160 %(2025-03 약 $560). "Ru 가 싸다"는 지금은 틀림. Pt 채굴 부산물이라 시장이 작고 변동이 크다.
- **반응도**: 알칼리 HOR 교환전류 Ru/C 3.09 vs Pt/C 1.08 mA/cm²(Nat. Commun. 2024, [조각]) = 2.86배. Ru 의 친산소성(OH 공급)이 알칼리의 느린 Volmer 단계를 돕는다는 설명이 일반적.
- **이점의 원인 분해**: 전류/질량 = j0비 2.86 x 밀도 역비 1.73(21.45/12.37, 같은 입경) ≈ 5. 같은 성능이면 Ru 0.5 mg/cm² $3.55 vs Pt 2.48 mg/cm² $18.31 -> 약 81 % 저렴. 같은 USD 로 Ru 원자 약 2배(몰질량 101 vs 195).
- **효율 이득은 작다**: 이 셀은 Ni 전극·옴 손실이 지배해서 같은 담지량이면 효율 차 0.25 %p. Ru 0.1 mg/cm² ≈ Pt 0.5 mg/cm² 성능.
- **깨지는 조건**: j0비 불재현(-> 이득 ~42 %, 면적 효과만), Ru/C 400 분 −56.5 % 열화 보고(3 %Pt-Ru/C 는 −19.3 %), 가격 추가 상승, 소형 셀에선 촉매비 ≪ 용기·전자부.
