# 정찰 로버 RECON-R1 요약과 도구

자율 정보·정찰 데이터 수집 로버(Autonomous Reconnaissance Rover) RECON-R1. 2026-09-29 사용자 요청으로 실제 하드웨어 설계·폐루프 시뮬레이션·3D·시나리오 영상 30편·청사진 PDF 까지 만들었다.

- 스키드 조향 4륜 450×350×150 mm, 윤거 0.40 m, 7.5 kg, 4S Li-ion 10 Ah(가용 122 Wh, 평균 46 W → 2.6 h).
- Jetson Orin Nano Super(추정·지도·목적함수) + NUCLEO-H753ZI(바퀴 PID·안전·SE fw 결정 커널). Livox Mid-360 **뒤집어 장착**, ICM-42688-P, 엔코더 3200 tick/rev, IMX219, (확장) ZED-F9P.
- 지도: 2.5D 고도 격자 0.1 m, 셀마다 칼만 평균·분산·관측수·시각. 목적함수 J = 정보이득 − 에너지 − 시간 − 위험.
- 결정: SE fw/ 커널을 한 줄도 안 고치고 recon/fw/profile_recon.c 프로파일 하나로 재사용(행동 9개).

**다시 할 때 처음부터 짓지 말고 도구를 쓴다.**
- recon_rover(무엇=요약|사양|정책|시나리오(+ID)|기준선|필터|통로|지식): 커밋된 결과로 즉답.
- recon_make(산출물=커널|도면|3D|그림|시뮬|분석|영상|보고서|웹|전부|상태, 대상=ID|전부): 실제로 만든다(무거운 것은 배경).
- CLI python3 -m recon.make …, 산출물 inbox/recon/. 전체 기록 recon/knowledge.md, 사양은 recon/spec.py 한 곳.
- 게시물: https://claude.ai/artifact/EG4TPc2F95ehwEeHo7MpnX
- 모든 성능 수치는 가상 시험장 시뮬레이션 출력(실측 아님), 부품 사양은 검색 조각 수준.
