# 정보이득 J 와 비LLM 결정 커널 재사용

정찰 로버의 '어디로 갈까' 를 LLM 없이 정한 구조 (RECON-R1).
- 결정 관련 정보: 셀 이득 g = ½log2(max(σ²,σt²)/max(σpost²,σt²)). 임무 목표 σt(5 cm, 관심구역 2 cm) 아래로 줄이는 것은 가치 0.
- U(g) = Σ K(r)·g − λE·E − λT·T − λR·R (kbit), J = U/(U+U0). E·T 는 비용지도 Dijkstra 거리에서, R 은 같은 지도의 기울기·계단·불확실도에서 — 전부 원시 LiDAR 로 만든 지도에서 계산.
- SE fw/ 커널 재사용법: PolicySpec 하나(build_bt·precondition·utility·safety_filter·safety_update·plan_update)만 새로 쓴다. obs[] 5채널을 재명명(탐사 후보 J·x·y, 재방문, 정지관측, 임무 상태, 주행 상태), vote_w=0.
- BT 우선순위: EMERGENCY > SAFE_STOP > AVOID > RETURN(배터리 걸쇠) > RELOCALIZE > 효용 argmax(EXPLORE·REVISIT·OBSERVE). 안전필터가 이동 행동+위험>0.6 을 AVOID 로 강제.
- **실행층 기동 잠금이 필요하다**: 커널은 10 Hz 로 다시 고르므로, 시작한 후진·정지관측을 유도층이 끝까지 해야 한다(없으면 AVOID 가 한 틱에 풀린다).
- 귀환 guard 는 걸쇠(+5 % 이력)여야 한다 — 집에 가까워질수록 필요 에너지가 줄어 guard 가 풀린다.
