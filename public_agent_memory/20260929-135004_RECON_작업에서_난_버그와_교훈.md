# RECON 작업에서 난 버그와 교훈

RECON-R1 시뮬레이터를 지으며 난 버그 11개 — 전부 참값 대조를 붙이자 드러났다. 수만 보고 믿지 않는다.
1. 0.1 s LIO 미분이 잡음을 슬립으로 읽음(0.04 → 0.21) → 1 s 창, LIO σ<5 cm 일 때만.
2. 먼 셀 잡음이 가짜 5 cm 계단 → 지도 42 % 치명 → 계단에서 2σ 를 뺀다.
3. 기동 잠금 없음 → AVOID↔EXPLORE 189회.
4. 발밑 LiDAR 사각 → 프런티어가 제자리 → 발자국 셀 채움.
5. 먼지 허공 점이 장애물 → 센서 잡음 태그 비율로 건강, 2 m 안쪽 폐기.
6. 완료 플래그 래치 → 영원히 귀환.
7. **EKF 과신**: σ 0.9 cm 라 믿으며 3.3 m 틀리고, 게이트가 좋은 LIO 를 계속 버림 → 연속 기각 3회 = 발산, 공분산 팽창. ATE 1.46 m → 8.3 cm.
8. 경사창이 벽을 번지게 해 1.2 m 틈이 막힘. 9. 벽에 붙은 목표 → 영원한 정지 교착. 10. 에너지 압력 과대·귀환 걸쇠 없음. 11. 배터리 비율 정의로 처음 7 Wh 동안 100 % (영상을 보고 발견).
환경 교훈: `pgrep -f` 나 `ps | grep` 패턴이 내 셸 명령줄에도 걸려 셸이 죽는다(두 번). setsid 로 띄운 배치를 못 보고 두 벌 돌렸다 — PID 로 기다린다. 테스트용 Chromium 에는 H.264 코덱이 없다(영상 readyState 0 은 파일 탓이 아님).
