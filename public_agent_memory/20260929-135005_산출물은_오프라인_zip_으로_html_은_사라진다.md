# 산출물은 오프라인 zip 으로 html 은 사라진다

사용자(2026-09-29): "html 에 영상이랑 정리된 내용을 저장하고 싶은데 html 은 사라지잖아. pdf·영상 전부·html 내용 전부 zip 으로."
- 인터랙티브 페이지(artifact)만 주지 말고 **오프라인으로 열리는 묶음**을 같이 준다: index.html(CDN 대신 lib/ 에 three.js 동봉, 영상·도면은 상대 경로) + PDF + 영상 전부 + 도면 PNG/SVG + 3D + 소스 + README.
- 파일 전송 한도는 30 MiB 다 → 묶음을 30 MiB 아래 여러 zip 으로 나눈다(같은 폴더에 풀면 하나로 합쳐지게). 첫 zip 에 페이지·PDF·README.
- 오프라인 검사는 네트워크를 막고(route abort) file:// 로 열어 3D·라벨이 뜨는지 본다.
