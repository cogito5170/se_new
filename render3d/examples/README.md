# render3d 예제 배치

| 파일 | 내용 | 근거 |
|---|---|---|
| `hongdae.json` | 카카오프렌즈 홍대 플래그십 B1·F1·F2·F3 **제안안** | 공개 연면적 1,150 m²와 층별 용도만 맞춘 **추정 외곽** 26.0×14.6 m. 실측 아님 |
| `store_module.json` | 24×14 m 가정 모듈의 `asis`(일반 캐릭터숍 배치 유형 가설)와 `tobe`(제안) | 특정 매장이 아님 |

좌표는 m이고, 원점은 앞(도로 쪽) 왼쪽 모서리, y는 매장 안쪽(북)입니다.
실측 치수가 생기면 `W`, `D`, `columns`, 계단과 EV 항목만 고쳐도 도면·3D·면적표가 모두 다시 나옵니다.
