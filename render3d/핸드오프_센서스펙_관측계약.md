# 핸드오프 — 3D 가시성/렌더 세션용 센서 스펙 · 관측 계약 (V&V 공간 분리)

이 문서는 **별도 세션**이 `render3d/`(3D 가시성·장면)를 지을 때 지켜야 할 계약이다. 목적은
참조세계(심판)가 3D 장면에서 가시성을 계산해 **관측을 생성**하도록 하는 것 — SUT 에 영상을 주는
것이 아니다. 아래 센서 파라미터와 맞물리게 만들면, 지금 돌아가는 결정 executive·실측 파이프라인이
그대로 재사용된다.

## 0. 절대 원칙 — V&V 공간 분리

```
[참조세계=심판]  DEM/장면/truth → 가시성(3D) → 물리 센서모델 → 관측(탐지 패킷)
                                                                   │  (이 선을 넘는 건 관측뿐)
[선수=SUT]                                              관측만 받음 → 정책 → 행동
```

- SUT 는 **truth·장면·3D 를 절대 못 본다.** 지금도 SUT 는 영상이 아니라 **탐지 패킷**을 받는다.
- 3D 는 참조세계 안에만 산다. 렌더 결과(영상/마스크)는 **가시성 수치를 계산하는 중간물**이지
  SUT 입력이 아니다.
- `render3d/` 는 참조세계가 부르는 모듈이다. SUT(`sar/ivv/sut.py`·`policies.py`)는 import 하지 않는다.

## 1. 지금 SUT 가 받는 관측(바꾸지 말 것 — 이 스키마로 채워라)

`sar/ivv/reference.py` 가 SUT 에 주는 관측 dict (센서별):
- `rgb`: `{vis: 0..1, detections: [(x,y,conf), ...]}`
- `thermal`·`lidar`·`sar`·`audio`: `{detections: [...], ...}`
- `imu`: `{ok: bool, sigma: float}` · `gps`: `{uncertain: bool}`
- `live`: `{detections: [(x,y), ...]}`  (liveness 채널; 아래 §4)

3D 를 켜도 **이 스키마는 그대로**다. 3D 는 `detections`·`vis` 를 **어떻게 계산하는지**만 바꾼다.

## 2. 지금 탐지 물리의 한계(= 3D 가 메울 것)

`reference.py`·`policies.ref_detect_prob_proxy` 확인 결과:
- **지형 가시선 없음** — 사거리는 `hypot(수평거리, 고도)` 뿐. 능선 뒤 표적도 보인다고 나온다.
- **수관 가림이 상수** — 표적마다 참/거짓 깃발 × 0.25·0.1. 나무의 실제 위치·각도 미반영.
- **표적 픽셀 수·FOV 없음** — 카메라 해상도가 탐지에 안 들어간다.

## 3. 3D 가 참조세계에 돌려줄 값 (센서 파라미터와 맞물리는 지점)

`render3d/visibility.py`(numpy, 브라우저 없이 몬테카를로 가능)가 (표적, 카메라 pose, 장면)마다:

| 반환값 | 자료형 | 어느 센서 파라미터로 들어가나 |
|---|---|---|
| `terrain_los` | bool | 능선 뒤면 전 광학센서 관측 0 (지형 가시선) |
| `canopy_vis` | 0..1 | 실제 나무 기하 기반 가시비. 지금의 상수 ×0.25 를 대체 |
| `pixel_count` | float | Johnson 식 → 탐지확률(탐지50%≈2px). RGB/Thermal 에 |
| `slant_m` | float | `sensors_ref` 의 range 인자(현재도 있음) |
| `aspect_deg` | float | 시야각 — 열대비·픽셀수 보정 |

**센서 물리는 `sar/sensors_ref.py` 를 그대로 쓴다(재구현 금지):**
- `thermal_dn(T_scene, T_amb, emissivity, V, range_m)` — LWIR Planck+대기. `V`(시정)·`range_m` 를 3D 가 채운다.
- `lidar_return(true_range_m, reflectivity, V)` — `true_range_m` 를 3D LOS 로.
- `rgb_raw(radiance, env={V, range_m, illum})` — `range_m`·`V`·`illum`.
- `audio_detect(...)` — 소리는 가림 통과(3D 가림을 audio 엔 약하게).

## 4. liveness 채널 — 이미 물리모델 있음(재구현 금지)

`sar/liveness_ref.py`: RF 마이크로도플러 심폐 위상 `φ=(4π/λ)x`, `x=호흡+심박`. 판별통계 = 위상
[0.15,2]Hz 대역에너지. 실측: SNR 6dB 서 AUC 0.977 (live vs non-live). 3D 는 **liveness 소스의
가시선·거리**만 주면 된다(관측공간 분리는 §0 대로).

## 5. 검증 시나리오 축 (실측이 요구 — 사람 vs 나무만 만들지 말 것)

```
Scenario = Target × Environment × Sensor × Geometry
Target   : 정지 사람 · 보행 사람 · 부분가림 사람
Decoy    : 식생 · 햇빛데운바위 · 동물 · 이동체 · 정적열원
Environment: 무풍·미풍·강풍 · 주간·야간 · 그림자 · 열배경변동
Geometry : 고도 · 시야각 · 표적크기 · 가림 · 사거리
```
각 칸에서 `P(관측 | H_T, E)` 와 `P(관측 | H_D, E)` 를 잰다. 이미 있는 실측 도구:
- `sar/observable_stack.py` — 관측 스택 × decoy × 환경 → AUC·Z_min(E) (이 세션이 만든 것).
- `sar/ivv/cmpc_vv.py` — CMPC 정보집합 스윕(N=200).

## 6. scene3d 깃발 계약 (기존 결과 불변)

- `reference.py` 에 `scene3d=False` 기본. **꺼지면 지금과 비트 단위로 같다** — 기존 IV&V 결과·검사 불변.
- 켜면 §3 의 3D 가시성으로 `detections`·`vis` 를 계산.

## 7. V&V 이중 경로(가시성도 독립 대조)

- `canopy_vis`·`terrain_los` 를 **두 독립 방법**으로 구해 대조: (a) numpy 광선 기하, (b) three.js 마스크 렌더.
  `|Δ| ≤ 0.05` 아니면 실패. (참조세계 안의 IV&V — 개발자 주장이 아니라 대조로.)
- 지형 가시선은 `sar/camera.py` 의 기존 가림과도 대조.

## 8. Fidelity 등급(산출물마다 찍을 것)

- L1 합성 지형 · **L2 실측 DEM + SceneDB** · **L3+ 는 이 저장소에 없음(명시)**.
- 3D 장면 자체의 실증(실 비행영상 대조)은 실측 영상이 없어 **GAP** 으로 남긴다(Blender-TRN 선례처럼).

## 9. 사소한 설명부터 죽인 뒤에 효과를 말할 것

탐지율이 바뀌면 먼저 확인: 표적이 FOV 밖으로 났나 · 수관 가시비가 상수와 비슷해 잎틈 가정을 상수에
맞춘 것뿐인가 · 동작점(BER·수렴)이 성한가. 못 죽였으면 발견이 아니라 후보다.
