# Handoff: Claude (implementation) → Antigravity (execution & validation)

**Phase owner:** Claude implemented the project and ran its tests in a cloud development container.
**Next owner:** the Antigravity execution agent runs and validates the project on its own VM.
Nothing here assumes access to Claude's container, files, credentials or state. Everything
needed is in this directory of the repository, which is transferred through git (`cogito5170/se_new`, directory
`visual_culture_platform/`). The directory is self-contained: it can be copied out of the repository and used on its own.

> Claude has **not** observed any Antigravity run. Results in TEST_RESULTS.md are Claude's runs.

## 0. Get the code (do this first)

The project is **not** a separate repository. It is the directory `visual_culture_platform/` on
the `main` branch of `https://github.com/cogito5170/se_new`. Do not substitute another workspace
or another project's test suite (e.g. a `visual-culture-pilot` / `tests/test_collector.py`): its
results say nothing about this project.

```bash
# new checkout (a private repo needs GitHub credentials on the VM)
git clone https://github.com/cogito5170/se_new.git
cd se_new

# or an existing checkout of se_new
git fetch origin main && git checkout main && git pull origin main

# sanity check: all three must print a path; if not, stop and report "code not present"
ls visual_culture_platform/tests/run_tests.py visual_culture_platform/HANDOFF.md \
   visual_culture_platform/scripts/acceptance.sh
```

If the VM cannot reach GitHub, copy the `visual_culture_platform/` directory over by any other
means. It is self-contained.

## 1. First command

```bash
cd visual_culture_platform && python3 tests/run_tests.py
```

The runner prints one `PASS`/`FAIL` line per test (73 lines), followed by a summary line. The
summary must read `73 passed, 0 failed`. A different count means a different or incomplete tree.

Expected: the last line is `73 passed, 0 failed in …s` and the exit status is 0.
It needs only Python ≥ 3.11 with no packages installed, and it uses no network.

## 2. Then

```bash
bash scripts/acceptance.sh /tmp/magref-acceptance       # expect "42 passed, 0 failed", exit 0
```

Next, follow [ACCEPTANCE_TESTS.md](ACCEPTANCE_TESTS.md): Level 3 is the manual checks, and Level 4
is the optional live check.

## 3. Installation (choose one)

| Mode | Commands | Needs |
|---|---|---|
| no install | `export PYTHONPATH=$PWD/src; python3 -m magref --help` | Python 3.11+ |
| editable install | `python3 -m venv .venv && . .venv/bin/activate && pip install -e .` | PyPI access (setuptools) |
| with extras | `pip install -e ".[images,dev]"` | PyPI; adds Pillow (colour/brightness, thumbnails, decode check), pytest, jsonschema |
| offline editable | `pip install --no-build-isolation --no-deps -e .` | setuptools already present |

## 4. Configuration

All configuration is optional. Copy `.env.example` to `.env`, export variables, or pass flags.

| Setting | Default |
|---|---|
| data root (`VC_ARCHIVE_DIR` = `MAGREF_DATA_DIR`) | `~/visual_culture_archive` |
| database | `<root>/database/references.sqlite3` |
| log | `<root>/logs/magref.log` |
| `--fixtures DIR` / `MAGREF_FIXTURE_DIR` | not set; when set, all HTTP is served from local files (offline mode) |
| `MAGREF_ALLOW_LOOPBACK=1` | off; **for tests only** |

No API keys or secrets are used anywhere.


## 6. Expected outputs

- Data layout: `<root>/images/<publisher-slug>/<YYYY>/<sha[:2]>/<sha256>.<png|jpg|gif|webp>`,
  plus `thumbnails/`, `database/`, `manifests/pending/`, `exports/`, `logs/`, `tmp/` and `quarantine/`.
- `magref export --kind images|pages` writes a validated envelope
  `magazine_reference_export/1`. Its records follow `magazine_image_reference/1` or
  `magazine_reference/1`; see [DATA_MODEL.md](DATA_MODEL.md).
- `magref project report --project N -o report.md` writes a 9-section planning report with
  provenance labels.
- **Exit codes:** 0 ok, 1 failure, 2 usage, 3 not found, 4 policy refused, 5 invalid,
  6 completed with errors.

## 7. External access requirements

| For | Needs |
|---|---|
| tests, acceptance script, offline demo | **nothing external** |
| live collection | outbound HTTPS **without a mandatory proxy** (see KNOWN_ISSUES), DNS, a meaningful `MAGREF_USER_AGENT`, and a **human policy decision with evidence for each source** (SOURCE_POLICY.md) |

the reserved `.test` TLD.
